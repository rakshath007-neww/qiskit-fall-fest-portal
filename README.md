# Qiskit Fall Fest Portal

Create a modern, responsive website for Qiskit Fall Fest 2026 — R.M.K. Engineering College, inspired by https://qffrguktsklm.in/, with original branding.

Dates: October 11–14, 2026 • 4 days • Fully virtual.

Use a futuristic dark theme, blue/violet accents, subtle quantum animations and clean typography. Include Home, About, four-day Schedule, Workshops & Challenges, Speakers, Organizing Team, Registration, FAQs and Contact. Add a countdown and prominent “Register Now” buttons.

Build working registration with confirmation and a participant dashboard for session links, resources and announcements. Keep meeting links restricted to registered participants. Use editable placeholders for unconfirmed schedules, speakers and contact details; do not invent prizes or sponsorships. Make it mobile-friendly and accessible.
